
# Задачи по нелинейной динамике (физика ускорителей)

В этом репозитории собраны восемь самостоятельных Jupyter-ноутбуков, посвящённых классическим задачам нелинейной динамики в физике ускорителей. Каждый ноутбук сочетает краткую теорию, аналитические выкладки и воспроизводимый Python-код (NumPy/SciPy/Matplotlib) для моделирования, визуализации и проверки физических эффектов.

- task_2.ipynb — Теория возмущений первого порядка для осциллятора с медленно меняющейся частотой; эволюция адиабатического инварианта.
- task_3.ipynb — Параметрический резонанс (точная огибающая vs численный расчёт); исправленная визуализация теоретической огибающей.
- task_4.ipynb — Эволюция бетатронных частот при выключенном ВЧ; зависимость от импульса через хроматизм и потери энергии.
- task_5.ipynb — Сдвиг частоты в 4-пучковой скомпенсированной схеме; компенсаторы противоположного знака; сдвиг по градиенту; нулевой сдвиг при a = 0.

## Краткое описание задач

### Задача 1 — Параметрический резонанс, экспоненциальная частота
- Модель: \(\ddot{x} + \omega_0^2 e^{2\lambda t} x = 0\)
- Цели: транспортная матрица; адиабатический инвариант; фазовые траектории.
- Особенности: решение через специальные функции; проверка адиабатичности при медленном изменении.

### Задача 2 — Теория возмущений, медленно меняющаяся частота
- Модель: \(\ddot{x} + \omega_0^2 (1 + \alpha e^{\lambda t}) x = 0\), \(|\alpha| \ll 1\)
- Метод: теория возмущений первого порядка; скорость изменения невозмущённого инварианта \(I_0\).
- Результат: малые поправки к действию/инварианту при плавном дрейфе параметров.

### Задача 3 — Параметрический резонанс: точная огибающая и численный расчёт
- Суть: сопоставление численного решения с правильной теоретической огибающей.
- Исправление: используется точная огибающая (а не только асимптотика) для сравнения с числом.
- Результат: согласие между численной амплитудой и аналитической огибающей.

### Задача 4 — Эволюция бетатронных частот при выключенном ВЧ
- Сценарий: ВЧ выключено; нелинейные поля отсутствуют; собственным полем пучка пренебрегаем.
- Механизмы: спад энергии/импульса (например, синхротронное излучение на высоких энергиях) меняет фокусирующую силу \(k \sim 1/p\).
- Хроматизм: тюны \(\nu_{x,y}\) зависят от \(p\): \(\Delta \nu / \nu = \xi \cdot \Delta p / p\). Натуральный хроматизм обычно отрицателен.

### Задача 5 — Сдвиг частоты в 4-пучковой скомпенсированной схеме
- Геометрия: центральное взаимодействие компенсируется двумя пучками противоположного знака, смещёнными на \(\pm a\).
- Ключ: при \(a=0\) компенсация полная → суммарная сила и её градиент равны нулю → сдвиг частоты ноль.
- Метод: теория возмущений первого порядка (линеаризация). Эффективное изменение фокусировки определяется **градиентом** суммарной силы на орбите.
- Результат: форм-фактор градиента для круглого гауссова пучка с смещением \(a\) выражается через \(u = a^2/(2\sigma^2)\). Сдвиг с компенсацией: \(1 - F'(a)/F'(0)\), растёт от 0 при \(a=0\).

### Задача 6 — Нелинейная резонансная кривая (detuning по амплитуде)
- Detuning по амплитуде: для одинаковых знаков зарядов (отталкивание, дефокусировка) \(\xi < 0\); backbone \(\nu(A)\) возрастает с амплитудой ("жёсткая пружина").
- Усреднённый гамильтониан (действие–угол): во вращающейся системе стационарные точки дают **точные ветви резонанса**:
	\[ \nu_{dr} = \nu(A) \pm \frac{C}{A} \]
	где \(C\) пропорционален силе возбуждения.
- Интерпретация: две ветви огибают backbone, формируя классический "язык" нелинейного резонанса.

### Задача 7 — Сдвиг частоты от ионного облака вдоль сгустка
- Модель: скорость образования ионов ∝ локальной плотности пучка; ионы практически неподвижны за время пролёта сгустка.
- Распределение: накопленная плотность ионов (и сдвиг частоты) растёт вдоль координаты сгустка; формируется продольный профиль сдвига.
- Результат: сильнейшая фокусировка там, где плотность ионов выше.

### Задача 8 — Резонансные кривые вдоль поезда сгустков (накопление ионов)
- Мульти-сгусток: плотность ионов увеличивается с номером сгустка (например, \(\rho_{ion}(n) \approx \rho_{sat}(1 - e^{-n/\tau})\)).
- Backbone для каждого сгустка: \(\nu_{osc}(A,n) = \nu_0 + \Delta \nu(A,n)\), где \(\Delta \nu\) определяется плотностью ионов и форм-фактором по амплитуде.
- Результат: поздние сгустки испытывают больший detuning и более выраженный наклон резонансной кривой; условия устойчивости меняются вдоль поезда.

## Как читать графики

- Backbone-кривая: собственная частота как функция амплитуды \(\nu(A)\).
- "Язык" резонанса: ветви \(\nu(A) \pm C/A\), ограничивающие область устойчивых стационарных колебаний при периодическом возбуждении.
- Detuning по амплитуде: для отталкивания (одинаковые заряды) эффективная фокусировка усиливается с амплитудой → пик резонанса смещается вправо.
- Компенсация (Задача 5): пучки противоположного знака могут обнулить detuning при полном перекрытии; разнос \(a\) разрушает компенсацию и восстанавливает сдвиг.
